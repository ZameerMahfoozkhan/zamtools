Base64 Size Overhead Notice

Base64 encoding increases data size by approximately 33% due to representing binary bytes as 6-bit ASCII characters. Use Base64 primarily for small icons (under 10KB) to save HTTP round-trips, not for large photographs.

Le tue immagini restano sul tuo dispositivo.

A differenza dei convertitori tradizionali che caricano i file su server cloud remoti, ZamTools elabora le immagini localmente nella memoria del tuo browser. Nessun file viene archiviato o inviato all'esterno.

Consiglio tecnico

Usa Base64 per icone inferiori a 10KB o per newsletter HTML, dove le immagini esterne possono essere bloccate dai client di posta.

FAQ

Domande frequenti

La codifica Base64 mappa 3 byte binari su 4 caratteri ASCII, comportando un incremento naturale di circa il 33% del peso.

Nei template email, per icone essenziali sopra la piega o per trasferire immagini via JSON in API REST.
