FAQ

Questions fréquentes sur les formats sociaux

Le format standard recommandé est de 1280x720 pixels (ratio 16:9) avec un poids inférieur à 2 Mo.

Facebook recompresse fortement les images qui n'ont pas les dimensions exactes recommandées. Utiliser nos gabarits résout ce problème.
